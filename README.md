# Dr. Arooba Zeeshan & Muhammad Waleed — Baraat Invitation

A single-page, mobile-first digital wedding invitation designed for sharing through WhatsApp.

## Scope

- One continuous scrolling page
- Opening "Open Invitation" cover
- Couple reveal
- Baraat
- 27 December
- Venue heading only for now
- Closing
- No RSVP
- No forms
- No backend/database

## Stack

Next.js + TypeScript + Tailwind CSS + Framer Motion

## Start

npm install
npm run dev

Then open http://localhost:3000
